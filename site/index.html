how it works
Touch ID→ WebAuthn PRF · 256-bit entropy→ BIP-39 · 24 words→ BIP-44 · m/44'/60'/0'/0/i→ in-memory signer · zeroed after every signature

Standard derivation — the phrase stays re-derivable from your passkey and imports into any BIP-44 wallet. Keys are never written to disk and never leave your device.

install

Up and running in two minutes.

Get the build

Clone github.com/tuantqse90/merawallet and run npm i && npm run build — it produces dist/.

Load in Chrome

Open chrome://extensions, enable Developer mode, hit Load unpacked and pick the dist folder.

Create with a passkey

The passkey console opens — one Touch ID prompt and your Monad wallet exists. On a Mac, save the passkey to iCloud Keychain.

Chrome Web Store listing is in review — soon it's one click. Requires Chrome 122+ and an authenticator with the WebAuthn PRF extension (iCloud Keychain, Google Password Manager on Android, YubiKey 5+).
